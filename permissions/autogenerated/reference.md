## Default Permission

Allows storing, reading, and deleting encrypted key-value items, and
managing the optional app-level lock password used by `requireAuth:
"password"` items.

#### This default permission set includes the following:

- `allow-set-item`
- `allow-get-item`
- `allow-delete-item`
- `allow-set-lock-password`
- `allow-change-lock-password`
- `allow-remove-lock-password`
- `allow-unlock-with-password`
- `allow-lock-keystore`
- `allow-lock-status`
